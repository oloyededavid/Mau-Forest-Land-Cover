Reference labelling

Each point is a random 20 m cell from the 2025 map, drawn within each mapped class. The map class is not shown, so you label blind. Label the class that covers most of the yellow square, using the imagery as close to 2025 as you can judge. Choose Unclear if the imagery is too old, cloudy or blurred to decide. The outer dashed square (60 m) is only for context.

Labels are kept in this browser while you work. Export the CSV when you finish, or to move to another browser, and save it as reference/labels.csv in the repository; scripts/s09_accuracy.py reads it. Please do not open reference_sample.csv while labelling: it holds the map classes.

–

Keys: 1 to 6 choose a class, arrow keys or N and P move, U jumps to the next unlabelled point, Z zooms to the point.
